# Primer Finder

日本語 · [English](README.en.md)

日本語版は `PrimerFinder.html`、英語版は `PrimerFinder_en.html` を開く。

Akira YoshinariがChatGPTを用いて作成した、ローカルブラウザで動作するプライマー検索ツール。

## 使い方

1. リポジトリを「Code → Download ZIP」からダウンロードし、展開する。
2. `PrimerFinder.html` をChromeまたはEdgeで開く。
3. 「Excelを選択」から手元のプライマーリストを読み込む。
4. DNA配列、または1レコードのFASTAを入力する。
5. 「完全一致」または「ミスマッチ許容」を選択して検索する。ミスマッチ許容では最大塩基数を0以上の整数で指定する。

追加インストールやサーバーの起動は不要。Excelは暗号化されていない `.xlsx`（30 MB以下）を使用する。

## Excelの形式

先頭のワークシートを読み込む。

| 列 | 内容 |
| --- | --- |
| A | プライマーID |
| B | 任意の情報（検索には使用しない） |
| C | プライマー配列（5′→3′） |

空白と改行を除き、大文字化して検索する。空の配列行を無視し、DNA配列として解釈できない行を除外する。

## 検索結果

- プライマー全長を正方向および逆相補方向で比較する。
- ミスマッチ許容では指定数以下の塩基置換を検索する。挿入・欠失のアラインメントには対応していない。
- 座標は入力配列の先頭を1とし、開始・終了の両端を含む。
- 複数箇所への一致と重なった一致も検索する。回文配列は「±」として表示する。
- 周辺配列は入力配列の向きで表示し、ミスマッチ塩基を色と下線で示す。
- 曖昧塩基（N、Rなど）は文字どおりに比較する。ワイルドカードとしては扱わない。
- 一致総数を表示し、一覧は先頭5,000件まで表示する。長い配列と多数のプライマーのミスマッチ検索には時間がかかる場合がある。

## Dropboxでの自動更新

1. `PrimerFinder.html` と `primers.xlsx` を同じDropbox共有フォルダに置く。
2. 各端末でフォルダをオフラインアクセス可にする。
3. FinderまたはエクスプローラーからHTMLを開き、「共有フォルダを接続」で対象フォルダを選択する。
4. 更新担当者が同じファイル名でExcelを保存すると、Dropbox同期後に画面が約5秒間隔で変更を確認する。表示中の検索結果も同じ条件で再計算する。

フォルダへのアクセス許可は起動時に与える。フォルダ接続に対応しないブラウザや環境では「Excelを選択」で手動読み込みする。自動更新にはDropbox側の同期完了が必要。

## データの取り扱い

Excelの読み込みと検索はブラウザ内で実行する。アプリは外部通信・外部ライブラリの取得・アクセス解析を行わない。プライマーリストと検索配列をアプリから送信しない。Dropboxに置いたファイルはDropboxによる共有・同期の対象となる。

このリポジトリにプライマーリストは含まれない。`.gitignore` でExcel・配列ファイルを除外している。

## 検証状況

Chromiumで、Excel読み込み、完全一致、ミスマッチ数指定、両方向検索、ミスマッチ表示、およびフォルダ更新の模擬テストを実施した。実際のDropbox共有フォルダでの同期は利用環境で確認が必要。
