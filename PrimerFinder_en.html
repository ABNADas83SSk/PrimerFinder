Using Dropbox
  1. Place this HTML file and primers.xlsx in the same shared folder. Make the folder available offline on each computer.
  2. Open the HTML file from Finder or File Explorer in Chrome or Edge, then select the shared folder each time you open the app.
  3. Save the updated Excel file with the same filename. While this page is open, changes are loaded after Dropbox syncs them to your computer. If folder access is unavailable, select the Excel file again after an update.

Whitespace is ignored. Full-length primers are compared in both orientations. Allow mismatches finds matches with up to the specified number of substitutions (no insertions or deletions). Ambiguous bases are compared literally.

Coordinates are 1-based and include both endpoints. Flanking sequences follow the orientation of the input sequence. Mismatched bases are underlined.
